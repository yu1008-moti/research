## 変数調査

### Code

|①|②|<span style="color: yellow;">③|④|<span style="color: yellow;">⑤|
|:-:|:-:|:-:|:-:|:-:|
|特殊取引|プット／コール現先区分|限月|権利行使価格等|対象指数等|
|1（**確定**）|6（**確定**）|10年サイクルの１桁 + 限月の月２桁|00（**確定**）|2桁

各先物の Code において ①・②・④ は全て同一であるため不要．<br>
以下の SQLクエリで再設定を行う．20yy年mm月が限月の銘柄ssは yymmss の形式で再設定．

```sql
DISTINCT SUBSTR(Code, 8, 2) || SUBSTR(CM, 3, 2) || SUBSTR(Code, 4, 2) AS newCode
```
