# 欠損データ補完 — Before / After

## 補完ルール

| ルール | 内容 |
|--------|------|
| 補完値 | 直前の有効な終値 `C(t-n)` で OHLC をすべて埋める |
| 出来高 | `0` で補完 |
| 連続欠損 | 最後に確認できた終値を伝播させる |
| フラグ | `is_filled = True` で補完行を明示 |

---

## Before — 補完前

```
 ticker       date   open   high    low  close  volume
      A 2024-01-01  100.0  103.0   99.0  102.0  1000.0
      A 2024-01-02  102.0  104.0  101.0  101.0   800.0
      A 2024-01-03    NaN    NaN    NaN    NaN     NaN   ← 補完対象
      A 2024-01-04    NaN    NaN    NaN    NaN     NaN   ← 補完対象（連続）
      A 2024-01-05  105.0  107.0  104.0  106.0  1200.0
```

---

## After — 補完後

```
 ticker       date   open   high    low  close  volume  is_filled
      A 2024-01-01  100.0  103.0   99.0  102.0  1000.0  False
      A 2024-01-02  102.0  104.0  101.0  101.0   800.0  False
      A 2024-01-03  101.0  101.0  101.0  101.0     0.0  True   ← C(t-2)=101 で補完
      A 2024-01-04  101.0  101.0  101.0  101.0     0.0  True   ← C(t-3)=101 で補完（連続伝播）
      A 2024-01-05  105.0  107.0  104.0  106.0  1200.0  False
```

---

## 補完の流れ

```
2024-01-02  close=101.0  ✅ 有効
     ↓
2024-01-03  NaN → 101.0  ✅ 補完 (is_filled=True)
     ↓
2024-01-04  NaN → 101.0  ✅ 補完 (is_filled=True)  ← 伝播
     ↓
2024-01-05  close=106.0  ✅ 有効
```

---

## 補完列の定義

| 列名 | 補完値 | 説明 |
|------|--------|------|
| `open` | `C(t-n)` | 直前終値で代替 |
| `high` | `C(t-n)` | 直前終値で代替 |
| `low` | `C(t-n)` | 直前終値で代替 |
| `close` | `C(t-n)` | 直前終値を継承 |
| `volume` | `0.0` | 取引なしとして扱う |
| `is_filled` | `True` | 補完行フラグ |
